# Shopping Bill Calculator

## Description
A basic Java program to calculate a shopping bill.

## Features
- Takes product price and quantity as input
- Calculates total bill
- Calculates 10% discount for bills of ₹500 or more
- Displays the final amount

## Technologies Used
- Java
- Scanner
- Arithmetic Operators
- if-else

## How to Run
Compile and run ShoppingBillCalculator.java using any Java compiler.
